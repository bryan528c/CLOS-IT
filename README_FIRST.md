# CLOs-IT Plan C 로컬 시연

스마트 옷장의 미러 화면에서 옷장·코디·캘린더·케어·프로필을 직접 조작하는 시제품입니다. 김수진·최휘재의 가상 생활 데이터와 옷 팩을 기존 기능에 연결했습니다. 카드의 의류 ID와 준비된 피팅 조합을 구분하며, 새로운 조합도 편집·저장할 수 있습니다.

이 저장소는 기존 팀 배포본을 덮어쓰지 않는 별도 공개 검토본입니다. 실제 고객 데이터·계정·로컬 사진·개인 저장값은 포함하지 않습니다.

## Windows에서 실행

1. Node.js **24 LTS**를 설치합니다.
2. 이 문서와 `package.json`이 함께 있는 폴더를 엽니다.
3. `Start-PlanC.cmd`를 실행합니다. 최초 실행은 잠금 파일 기준으로 의존성을 설치합니다.
4. 창을 유지하고 브라우저에서 **http://127.0.0.1:4311/** 을 엽니다. 오류가 나면 창의 원인을 확인할 수 있습니다.

터미널에서도 실행할 수 있습니다.

```powershell
npm ci
npm run dev
```

가입·로그인·`.env` 입력 없이 로컬 시연이 시작됩니다. 서버 코드는 보존했지만 실행만으로 유료 API를 호출하지 않습니다. 이미 같은 포트를 사용하는 앱이 있으면 그 앱을 확인한 뒤 새 실행을 시작하세요.

## 시연 방법

- **마이:** 김수진 또는 최휘재를 고른 뒤 `이 프로필로 시작`을 누릅니다. 각자의 의류·초안·달력으로 전환됩니다.
- **김수진:** 홈/옷장에서 트렌치코트를 열고 관리 현황 → 가이드 → 위치를 확인합니다. 가이드와 시연 라벨은 실제 상품 라벨 검증이 아닙니다.
- **최휘재:** 홈 추천 코디 → 준비된 피팅 → 카드 탐색 → 다른 코디/품목 편집 → 카드 저장 또는 날짜별 계획 저장을 사용합니다.
- **코디:** 카드 목록에서 기존 카드를 열어 초안으로 수정합니다. 상의만 교체하면 다른 품목은 유지됩니다. 원본 카드와 과거 일정은 새 초안과 별도로 보존합니다.
- **옷장:** 검색·종류 필터·상세·사진 등록을 사용할 수 있습니다. 등록 사진은 이 브라우저의 로컬 저장 공간에 보관됩니다.
- **캘린더:** 날짜를 선택해 기록을 확인하고 코디를 재사용합니다. 계획, 코디 카드 저장, 실제 착용 기록은 서로 다릅니다.

새로운 공개 사이트와 `127.0.0.1:4311`은 저장 공간이 다릅니다. PC의 저장값을 사이트로 자동 업로드하지 않습니다. 사이트 주소·브라우저가 같아야 해당 시연 저장값을 다시 읽을 수 있습니다. 브라우저 데이터를 지우면 그 브라우저의 저장값도 사라집니다.

## 가능한 기능과 한계

- 통합 팩은 프로필별 24품목, 코디 11종, 전신 착장 2종, 관리 가이드·시연 라벨 48종입니다. 기존 의류 데이터가 있는 앱에서는 전체 수량이 더 많으며 기존 항목을 지우지 않습니다.
- 준비된 두 전체 조합만 `reference_saved` 피팅으로 표시합니다. 실제 OpenAI/Decart 호출 결과가 아닙니다. 한 품목이 달라지면 이전 피팅을 그대로 사용하지 않습니다.
- 준비된 피팅이 없는 조합도 편집·카드 저장·날짜별 계획을 사용할 수 있습니다.
- B 코디 위치 대상 3벌 중 재킷은 정확 위치 보류입니다. 확인된 상의와 바지에만 시연 LED 2개가 켜집니다. 실제 하드웨어 LED 연결이 아닙니다.
- 작은 원본 의류 사진, 가려진 재킷 소매·바지 허리, 전경의 경계 품질은 남은 자산 한계입니다. 고해상도 원본을 복구했다고 주장하지 않습니다.
- 일부 과거 생활 의류의 사진 미연결은 그대로 표시합니다. 비슷한 옷으로 대신 채우지 않습니다.
- 실제 공급자 피팅, 인증·원격 저장은 별도 서버·사용 권한·자산·비용 승인 검증이 필요합니다. `.env.example`의 키는 비어 있으며 여기에 키를 넣는 것만으로 API 실행을 승인한 것이 아닙니다.

## 공개 사이트 빌드

```powershell
npm test
npm run build:pages
```

`dist-pages/`만 GitHub Pages에 게시합니다. base는 `/CLOS-IT/`입니다. 공개 사이트는 브라우저 로컬 시연이며 실제 API 요청은 명확한 사용 불가 응답을 반환합니다. 무료 Pages 정적 호스팅만 대상으로 합니다.

`main`에 push하면 `.github/workflows/pages.yml`이 포함된 독립 검사와 빌드 후 Pages artifact를 게시합니다. 원래 개발 프로젝트의 원격 DB·팀 운영 배포와 연결하지 않습니다.

## 검수 범위

`docs/PUBLIC_SNAPSHOT_QA_SCOPE.json`에 공개본에 포함한 검사 파일과 제외한 원본 자료 의존 검사를 기록했습니다. 원래 팩의 67개 검사·계약 10개 검사를 앱 브라우저 성공으로 합산하지 않습니다. 독립 공개본의 실제 결과와 최종 소스 버전은 `docs/PUBLIC_SNAPSHOT_VALIDATION.md`에 기록합니다.

과거 Git 이력·개인 로그·원본 조사 자료·녹화·비밀 설정은 공유하지 않습니다. 사진의 출처/라이선스는 `public/assets/README.md`, 자산 manifest와 함께 보존했습니다. 일부 과거 PNGimg 시연 사진은 비상업적 이용 조건이므로 상업용 전환 전에 권리를 확인해야 합니다.
