# 공개 snapshot 검수 기록

상태: 새 공개 폴더의 독립 설치·타입검사·격리 단위검사·정적 산출물 브라우저 검사 통과. 최종 소스 커밋과 동기화 확인 완료. 공개 URL 배포 검수는 별도입니다.

원래 Plan C의 최종 기준 커밋은 `11717583e80466eb959863a9737b4cf1dc3f0d55`입니다. 이 공개본의 앱 소스·서버·SQL·빌드 스크립트·잠금 파일·포함 검사 파일은 해당 커밋의 최종 파일과 일치합니다. 미커밋 앱 변경을 따로 포함하지 않습니다. 원본 Git 이력은 복사하지 않아 공개 저장소의 새 커밋 번호는 달라집니다.

- 원래 프로젝트의 소스·승인 실행 자산을 복사했으며 원래 Git 이력은 복사하지 않았습니다.
- 실제 `.env`, 원본 조사 자료, 개인 브라우저 저장값·사진, 로그, 이전 ZIP, 녹화, `.git`, node_modules는 포함하지 않았습니다.
- `.env.example`의 공개 snapshot 복사본에서만 `SUPABASE_URL`을 비웠습니다. 원래 예시와 실제 설정은 변경하지 않았습니다.
- 공개 자산 manifest의 원본 ZIP 파일명·엔트리·해시는 유지하고 개인 PC 디렉터리만 제거했습니다. 원본 이미지 바이트는 변경하지 않았습니다.
- 앱이 직접 import하는 생활 데이터 JSON 12개만 `reference/life-data-ready-20261009/SmartCloset_DataReady_v0.1`에 포함했습니다. manifest상 실제 사용자 행동·실제 인물 미디어를 담지 않은 시연 데이터입니다. 원본 문서·조사 HTML·영상·사진은 포함하지 않습니다.
- 비공개 원본/조사 폴더에 의존하지 않는 검사만 포함했습니다. 제외 목록을 성공으로 계산하지 않습니다.
- GitHub Pages 빌드는 `/CLOS-IT/` 경로를 사용하며 API·원격 저장을 실행하지 않는 정적 로컬 시연입니다.
- 배포 성공, 공개 URL 브라우저 성공은 별도 검증 전까지 미확인입니다.
