# CLOs-IT Plan C

가입 없이 브라우저 로컬 저장으로 사용하는 스마트 옷장 시제품입니다.

**[공개 사이트 열기](https://bryan528c.github.io/CLOS-IT/)** · [공개 주소 실제 검수 결과](docs/PUBLIC_DEPLOYMENT_VERIFICATION.md)

[한국어 시작 안내](README_FIRST.md)를 먼저 읽어주세요. Windows는 `Start-PlanC.cmd`, 터미널은 `npm ci` 후 `npm run dev`로 시작합니다.

소스는 기존 팀 서비스와 별도로 검토·통합할 수 있는 공개 snapshot입니다. 실제 고객 자료와 API 키를 포함하지 않습니다. 준비된 피팅은 두 조합의 시연 이미지이며, 실제 유료 API 실행·원격 저장 성공을 뜻하지 않습니다.
